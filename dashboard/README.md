# WhiteGrief Control Panel

Первая стадия веб-панели: статический интерфейс на HTML/CSS/JavaScript.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
cd dashboard
python -m http.server 8080
```

Затем откройте http://localhost:8080.

## Текущий статус

- Реализован тёмный адаптивный интерфейс.
- Добавлена навигация по разделам.
- Показатели явно обозначены как недоступные до подключения API.
